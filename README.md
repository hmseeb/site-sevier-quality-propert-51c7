# Sevier Quality Property &amp; Projects

Single-page marketing website for **Sevier Quality Property & Projects** — professional cabin
cleaning, vacation rental turnovers, remodeling, flooring installation, interior painting,
junk removal and full property maintenance in Sevier County, Tennessee
(Sevierville, Pigeon Forge and Gatlinburg).

## Stack

Vanilla HTML, CSS and JavaScript — no build step, no dependencies.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Entry point — all page sections and structured data |
| `styles.css` | Design system, layout and responsive rules |
| `script.js` | Mobile nav, scroll effects, reveal animations, form validation |
| `favicon.svg` | Site icon |
| `robots.txt` / `sitemap.xml` | Basic SEO files |

## Sections

Hero with call to action · Trust bar · Services (7) · Why Us · How It Works ·
Service Area · Testimonials · CTA band · Contact form · Footer

## Running locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Notes

- The quote form validates client-side and shows a confirmation message. Connect it to an
  email service or backend endpoint to deliver submissions.
- Photography is sourced from Pexels.
